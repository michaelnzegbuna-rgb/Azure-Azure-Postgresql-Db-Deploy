# Screenshot Submission Guide

Before submitting, replace each placeholder image in this folder with a real screenshot from your own Azure PostgreSQL deployment. Four screenshots are required, detailed below.

## 1. `server-overview.png`

Open the Azure Portal, navigate to your server, and screenshot the **Overview** blade. This image is your evidence that the server `psql-lab-olamileye` was actually deployed — it should clearly show a `Running` status and confirm the server is sitting in the `West Europe` region.

## 2. `firewall.png`

From the same server, go to **Networking** and switch to the **Public access** tab, then capture that view. The grader will be checking for one specific firewall rule in your screenshot: a rule labeled `AllowMyDevIP` that permits your own client IP address through.

## 3. `private-endpoint.png`

Stay in **Networking**, but this time open the **Private access** tab. This screenshot needs to demonstrate that the private endpoint `pe-psql-lab` is properly wired up — connected to the `snet-db` subnet within your VNet, and resolvable through Private DNS.

## 4. `connection_proof.png`

Finally, prove the database is actually reachable. Screenshot either pgAdmin 4's server tree or a terminal session running `psql`, with the connection visibly established. The session must show TLS enforced via `sslmode=require`, and the `labdb` schema visible/queryable in the same shot.

---

**Note:** Each file name above must stay exactly as listed so the grading script can locate it — only the image content should change.
